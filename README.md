# bizmoney-share

오피노 비즈머니 화면(Apps Script)에서 드림인사이트 충전 요청을 카카오톡 공유로 보내는 고정 주소 페이지.

- `index.html` + `share.js`: 비즈머니 화면이 `#d=<base64url JSON>`으로 연다. 계정 1개당 메시지 1개(텍스트형, 최대 200자).
- `v.html`: 메시지의 '요청 내용 복사' 버튼이 여는 페이지(`?t=<base64url 본문>`).
- 카카오 개발자 앱 '오피노 비즈머니'(ID 1657269, 회사 카카오 계정). JS SDK 도메인·웹 도메인 = https://opinno123.github.io
- 저장소에는 계정 데이터가 없다. 요청 내용은 주소 # 뒤로만 넘어가고 서버로 가지 않는다.
